# 🔎 OrionOSINT

**OrionOSINT** is a Python-based Open-Source Intelligence (OSINT) command-line toolkit for learning about publicly available information and performing basic analysis on files and network resources.

> ⚠️ **Educational & Responsible Use**
>
> Use OrionOSINT only on systems, files, domains, and network resources that you own or are authorized to investigate.
> OrionOSINT is not designed for unauthorized access, account compromise, surveillance, or disruption of services.

---

## ✨ Features

OrionOSINT currently includes:

- 🌐 Domain information
- 🔍 DNS record lookup
- 🌍 IP address analysis
- 🏠 Local/private IP detection
- 📡 HTTP header inspection
- 🔐 File hash calculation
- 🖥️ Interactive terminal interface
- 🎨 Rich terminal formatting
